# 附錄 B　現場行話

晶圓廠的日常溝通，常常是中文夾雜英文術語，例如「這批 Q-Time 快到了，先跑它」。剛入行的人第一次聽到，常常一頭霧水。

本附錄收錄晶圓廠裡常聽到的說法，並附上例句。各公司的習慣用語不完全相同，這裡整理的是業界普遍的講法。正式的術語定義請見[附錄 A 術語總表](glossary.md)。

行話大概可以分成三種。一種是**術語**，例如 Q-Time、Overlay，指的是有明確定義的東西；一種是**動作**，例如進站、Release、Bank，指的是某個人當下要做的事；還有一種是**狀態**，例如 Down、Hold、Idle，指的是某個東西現在怎麼樣。聽話的時候先分辨是哪一種，通常就不會誤會。

---

## 晶圓與批次

這一區的行話最常出現在交班、派工與生管會議上。判斷一句話是「描述現況」還是「要求動作」，是聽懂它的關鍵。

| 行話 | 意思 | 例句 |
|---|---|---|
| Lot | 一批晶圓，最多 25 片 | 「這個 Lot 今天要出貨。」 |
| 投片（Wafer Start） | 把空白晶圓投入生產 | 「這個月的投片量增加了。」 |
| 組批 | 把幾片晶圓組成一批，湊滿一個晶圓盒 | 「今天的組批進度落後，生管在催。」 |
| 拆批（Split） | 把一批晶圓分成幾組，做不同條件 | 「這批要 Split 成三組條件。」 |
| Merge | 把分開的晶圓合回同一批 | 「實驗做完就 Merge 回去。」 |
| 尾批 | 數量不滿一整盒的批次 | 「尾批先跑，別讓它卡在爐管前面。」 |
| Fab Out | 晶圓完成前段製程，離開晶圓廠 | 「這批預計下週 Fab Out。」 |
| Hot Lot | 優先生產的急件 | 「這批是 Hot Lot，到站先跑。」 |
| Bank | 讓晶圓暫停在某個步驟等待 | 「這批先 Bank 在金屬層前面。」 |
| WIP | 還在生產線上的晶圓 | 「黃光前面的 WIP 堆太多了。」 |
| Move | 一段時間內晶圓完成的步驟數，用來衡量產出 | 「今天全廠的 Move 有達標嗎？」 |
| 控片 | 用來檢查機台狀態的測試晶圓（Monitor Wafer） | 「先跑一片控片確認膜厚。」 |
| 擋片 | 用來填補空位或調整機台的晶圓（Dummy Wafer） | 「爐管空位記得補擋片。」 |
| 破片 | 晶圓破裂 | 「機械手臂取片時破片了。」 |
| 刮傷 | 晶圓表面被刮出痕跡 | 「這片的 Map 有一條刮傷，先隔離。」 |

## 機台

機台這一區的行話，多半是在講「它現在能不能跑」。所以最常聽到的是狀態詞，而不是技術詞。

| 行話 | 意思 | 例句 |
|---|---|---|
| Recipe | 機台執行製程用的參數組合 | 「這道的 Recipe 換新版本了。」 |
| PM | 定期保養 | 「這台今天下午排 PM。」 |
| Down（Down 機） | 機台故障或停用 | 「蝕刻機 Down 了，已經通知 EE。」 |
| 復機 | 機台修好、恢復生產 | 「這台預計晚上復機。」 |
| Qual | 確認機台狀態合格的驗證 | 「PM 完要先 Qual 過才能跑貨。」 |
| Seasoning | 保養後先跑擋片，讓腔體穩定 | 「先 Season 二十片擋片。」 |
| 暖機 | 開機或閒置太久後，先跑幾片讓狀態回穩 | 「這台剛暖機，先別排急件。」 |
| Chamber | 機台中實際做製程的腔體 | 「這片是在 B 腔做的。」 |
| Idle | 機台閒置、沒有晶圓可跑 | 「這台 Idle 很久了。」 |
| 綁機（Dedication） | 指定晶圓只能在特定機台上做 | 「這層要綁同一台曝光機。」 |
| 借機 | 向別的區域或廠區借用機台產能 | 「這批要借機跑，先確認 Recipe 有沒有。」 |
| UPH | 每小時產出片數 | 「這台的 UPH 掉了一成，要查一下。」 |
| Alarm | 機台發出的異常訊號 | 「昨晚這台跳了三次 Alarm。」 |
| Load Port | 機台前方放晶圓盒的平台 | 「Load Port 讀不到 FOUP 的編號。」 |

## 系統與流程

這一區是新手最容易卡住的地方，因為同一個詞可能同時是「系統上的狀態」和「現場的動作」。聽到「Hold」時，要問的是「誰 Hold 的、為什麼」。

| 行話 | 意思 | 例句 |
|---|---|---|
| 進站（Track-in） | 在系統上登記開始加工 | 「貨放上去記得先進站。」 |
| 出站（Track-out） | 在系統上登記完成加工 | 「機台跑完了，記得出站。」 |
| Hold | 暫停晶圓或機台的生產 | 「這批被 Hold 了，原因是 Q-Time 超過。」 |
| Release | 解除 Hold，放行繼續生產 | 「工程師確認沒問題，可以 Release。」 |
| Future Hold | 讓晶圓走到指定步驟時自動被擋下 | 「先設 Future Hold，到金屬層再決定。」 |
| 改派（Re-route） | 把晶圓改走另一條流程或另一台機台 | 「這台要保養，這批改派到隔壁線。」 |
| Q-Time | 兩站之間允許等待的時間 | 「這批 Q-Time 快到了，先跑它。」 |
| 派工 | 決定機台下一批要跑哪一批晶圓 | 「派工系統把這批排在最前面。」 |
| 跑貨 | 讓產品晶圓在機台上生產 | 「這台現在可以跑貨了嗎？」 |
| 帳實不符 | 系統紀錄和實際狀況不一致 | 「系統顯示已出站，晶圓卻還在機台裡，帳實不符。」 |

## 系統與資料

這一區的行話，這二十年增加得最快。以前工程師靠筆記本和經驗，現在靠報表和系統；聽得懂這些詞，才進得了早會。

| 行話 | 意思 | 例句 |
|---|---|---|
| 履歷（Lot History） | 一批晶圓走過的步驟、機台、時間與量測結果 | 「拉一下這批的履歷，看它經過哪些腔體。」 |
| 拉資料 | 從系統匯出某段時間或某批的生產資料 | 「先拉三個月的資料，看有沒有週期性。」 |
| 共通性 | 異常批次共同經過的機台、腔體或時段 | 「這幾批的共通性是同一台蝕刻機的 B 腔。」 |
| 開圖 | 打開管制圖或趨勢圖看變化 | 「這支參數上週就開圖了，一直沒收斂。」 |
| 回寫 | 把量測或測試結果寫回生產系統 | 「量測資料還沒回寫，先別放行。」 |
| 虛擬量測 | 用機台數據推估量測結果，取代部分實際量測 | 「這站有開虛擬量測，抽樣可以少一點。」 |
| FDC 告警 | 機台感測器數據偏離正常範圍的警示 | 「昨晚 FDC 告警了十幾次，都是同一支氣體。」 |
| 綁批 | 把前後批次的關係記錄下來，用於追溯 | 「這兩批要綁批，客戶要求整串追溯。」 |

## 品質與異常

這一區的詞聽起來都很嚴重，但實際上大部分事件最後只是「記錄、檢討、結案」。真正的判斷點是：這件事會不會影響已經出貨的產品。

| 行話 | 意思 | 例句 |
|---|---|---|
| OOC | 數據超出管制界限 | 「這點 OOC 了，照 OCAP 處理。」 |
| OOS | 數據超出規格 | 「膜厚 OOS，要開 MRB。」 |
| Rework | 重新製作，主要用在微影 | 「ADI 沒過，要 Rework。」 |
| Scrap | 報廢 | 「這片破片了，只能 Scrap。」 |
| 特採 | 不合格但經核准後仍可使用 | 「這批走特採，客戶已經同意。」 |
| 降級 | 把產品降到較低規格出售 | 「速度沒過，降級成低階型號。」 |
| 隔離 | 把有疑慮的晶圓單獨存放，暫不投入 | 「先隔離，等 FA 結果出來再說。」 |
| Excursion | 突發的品質異常事件 | 「昨天那次缺陷的 Excursion 影響了三批。」 |
| MRB | 跨部門判定不合格品處置的會議 | 「這批要開 MRB 決定。」 |
| Map | 晶圓圖 | 「看一下這片的 Map 有沒有刮痕。」 |
| Particle | 微粒 | 「這片的 Particle 數超標。」 |

## 可靠度與韌體

這一區的行話，出現在測試、客訴與韌體會議上。它們的共同點是：問題通常不會馬上出現，而是幾個月後才回來。

| 行話 | 意思 | 例句 |
|---|---|---|
| 燒機（Burn-in） | 在高溫高壓下運作一段時間，篩掉早期失效 | 「這批要燒機 48 小時。」 |
| 刷（Refresh） | 定期重寫 DRAM 資料 | 「高溫時刷新頻率要加倍。」 |
| 開 ECC | 啟用錯誤更正功能 | 「這顆控制器預設沒開 ECC，要記得開。」 |
| 勘誤（Errata） | 晶片已知問題與避開方法 | 「這條勘誤要在韌體裡補 workaround。」 |
| 改版（Stepping） | 晶片修正設計後的版本代號 | 「新版是 B0，只改了金屬層。」 |
| 抹寫次數（P/E） | 快閃記憶體區塊能被抹寫的次數 | 「這批 TLC 的 P/E 只剩幾百次。」 |
| 寫放大 | 主機寫一份，實際寫進快閃記憶體幾份 | 「寫放大跑到 3，壽命會差很多。」 |
| 客退（RMA） | 客戶退回的故障品 | 「這顆是客退品，先做 FA。」 |

## 區域與人

最後一區講的是「誰在做什麼」。晶圓廠的分工很細，找錯人會繞很大一圈。

| 行話 | 意思 | 例句 |
|---|---|---|
| 黃光 | 微影區，因照明是黃色而得名 | 「這批卡在黃光。」 |
| 爐管 | 氧化、退火等批次式高溫機台的區域 | 「爐管今天組批比較慢。」 |
| Wet | 濕式清洗與濕蝕刻區 | 「這道要先到 Wet 洗一下。」 |
| PE、EE、PIE、YE | 製程、設備、製程整合、良率工程師 | 「這個問題要找 PIE 判斷。」 |
| AE | 應用工程師，負責客戶端技術支援 | 「客戶那邊由 AE 先確認現象。」 |
| QA | 品質保證 | 「這個變更要 QA 簽過。」 |
| 值班 | 下班時間與假日負責處理異常的人 | 「今天值班是誰？機台跳 Alarm 了。」 |
| 交接 | 換班時說明機台與晶圓的狀況 | 「交接時要講清楚這台還在觀察。」 |
