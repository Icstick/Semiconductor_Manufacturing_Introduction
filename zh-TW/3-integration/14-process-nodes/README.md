## 「3 奈米」裡沒有 3 奈米

新聞常說某顆晶片使用「3 奈米製程」，很多人以為晶片上有某個東西只有 3 奈米寬。

事實上，在 3 奈米世代的晶片上，電晶體閘極之間的距離大約是四、五十奈米，找不到任何一個結構是 3 奈米。

真正落在幾奈米量級的，只有薄膜的厚度：閘極絕緣層、通道片的厚度，這些確實只有幾奈米。

但它們和「3」這個數字沒有對應關係。

「幾奈米」其實是一個**世代的名稱**，而不是實際的尺寸。

換個角度想：如果 3 奈米真的是 3 奈米寬，那條線只有十幾個原子寬，任何輕微的擾動都會讓它斷掉。光是這一點，就知道那個數字不可能是實際尺寸。

這件事不是廠商在騙人，而是名稱的用途變了。早期它是一個尺寸標籤，後來變成一個世代的代號，最後變成一種「大概比上一代好」的承諾。

---

## 名稱的由來

在半導體發展的早期，節點名稱大致等於電晶體閘極的長度，或是最密集線路的寬度，名稱和實際尺寸是對得上的。

產業習慣每一代把尺寸縮小到大約 0.7 倍。長和寬都乘以 0.7，面積就變成大約一半，同樣面積可以放進兩倍的電晶體。

所以節點名稱一路沿著 180、130、90、65、45、32、22、14、10、7、5、3 奈米這樣的數列往下走，中間還穿插了 40、28、20、16 奈米等「半世代」節點。

後來電晶體的結構越來越複雜，實際尺寸的縮小速度跟不上名稱，兩者就逐漸脫鉤了。

真正讓名稱失效的是結構的改變。閘極長度不再是唯一決定效能的因素，立體結構讓「一條線多寬」變得沒有意義；於是命名從「尺寸」轉向「等效」，用密度或效能換算成一個數字，再挑一個好聽的世代名。

近年也有公司改用「埃」（Å，0.1 奈米）來命名新世代，同樣只是世代代號。換一個單位，數字放大十倍，技術內容並沒有變。

### 名稱的三種寫法

- **奈米數**：傳統寫法，例如 7 奈米、5 奈米，代表一個世代
- **埃數**：把奈米乘十，例如 20 埃就等於 2 奈米，同一個世代換個說法
- **密度或效能代號**：直接標榜電晶體密度或效能提升幅度，避開尺寸的爭議

> [!NOTE]
> **📖 名詞｜製程節點（Process Node / Technology Node）**
>
> - **定義**：代表某一代製程技術的名稱，通常以「幾奈米」表示。
> - **現場用法**：「這個產品要從 7 奈米移到 5 奈米。」
> - **相關名詞**：微縮、摩爾定律、電晶體密度
> - **常見混淆**：節點名稱是世代代號，不是晶片上任何結構的實際尺寸，也和微影量測的 CD 是不同的東西。

## 原理：0.7 倍是從哪裡來的

為什麼每一代是 0.7 倍，而不是 0.5 倍？因為晶片的面積是「長乘寬」，兩個方向都要縮，面積才會減半。

- 長縮到原本的七成，寬也縮到七成
- 兩個方向一起縮，面積大約剩一半
- 同樣一片晶圓，能切出的晶粒數大約變兩倍

這就是摩爾定律真正的內容：不是「電晶體變多」，而是**每個電晶體變便宜**。

電晶體變多是結果，變便宜才是產業願意持續投資的原因。

因為晶圓的成本大致不變，晶粒數變兩倍，每顆晶粒分攤到的成本就砍半。

產業願意每年砸大錢研發，是因為這條算式過去幾十年都成立。一旦它不成立，整個投資邏輯就要重寫。

| 世代變化 | 線性尺寸 | 面積 | 同一片晶圓的晶粒數 |
|---|---|---|---|
| 不變 | 1.0 倍 | 1.0 倍 | 1.0 倍 |
| 一個世代 | 0.7 倍 | 約 0.5 倍 | 約 2 倍 |
| 兩個世代 | 0.5 倍 | 約 0.25 倍 | 約 4 倍 |

但這條算式這幾年開始鬆動。設備變貴、光罩變貴、設計變貴，晶粒數雖然變兩倍，每片晶圓的成本卻漲得更多。

於是「每顆晶粒更便宜」不再自動成立，產業的邏輯從「每顆更便宜」變成「每顆差不多，但效能更好」。

這也是為什麼節點名稱會脫鉤——當尺寸縮不下去，名稱就只能靠別的方式去描述「這一代好在哪裡」。

> [!NOTE]
> **📖 名詞｜摩爾定律（Moore's Law）**
>
> - **定義**：積體電路上可容納的電晶體數目，大約每隔兩年增加一倍。
> - **現場用法**：「摩爾定律變慢」通常指的是「每顆電晶體的成本不再下降」，而不是電晶體不再變多。
> - **相關名詞**：微縮、節點、密度、DTCO
> - **常見混淆**：摩爾定律是觀察與產業共識，不是物理定律；它描述的是經濟與工程的節奏，不是自然界的規則。

## 真正該看的尺寸

要比較兩個製程，比較有意義的是以下幾個數字：

- **閘極間距**（CPP，Contacted Poly Pitch）：相鄰兩個閘極之間的距離。
- **最小金屬間距**（MMP，Minimum Metal Pitch）：最密集那層金屬導線的間距。
- **電晶體密度**：每平方毫米能放進多少個電晶體，常用「百萬個電晶體／平方毫米」表示。
- **SRAM 單元面積**：一個 SRAM 記憶單元的大小，常被拿來當作密度的參考。
- **標準單元高度**：以「金屬軌道數」表示，數字越小，單元越矮、面積越省。

| 指標 | 看什麼 | 為什麼重要 |
|---|---|---|
| CPP | 閘極之間的距離 | 決定邏輯區能多密，也決定微影難度 |
| MMP | 最密金屬層的間距 | 決定佈線能不能塞得下 |
| 電晶體密度 | 每平方毫米的電晶體數 | 最直觀的面積效率 |
| SRAM 面積 | 一個記憶單元的大小 | SRAM 最難縮，常是密度的瓶頸 |
| 標準單元高度 | 幾條金屬軌道 | 直接決定邏輯電路的面積 |

其中 **SRAM 面積**特別值得看。邏輯電路可以靠設計技巧壓縮，SRAM 的每個位元就是六個電晶體排成的固定圖形，很難用巧思變小。

所以 SRAM 往往是最先撞牆的地方，也最能反映一個製程的真實密度。

另外要注意，密度這種數字也有算法上的差異：要用哪一層金屬的間距、算邏輯區還是含 SRAM 的整片、取最密還是平均值，算出來可以差一截。

> [!NOTE]
> **📖 名詞｜間距（Pitch）**
>
> - **定義**：重複排列的圖形中，一條線加上一個間隔的總寬度。
> - **現場用法**：「這層的 Pitch 太小，一次曝光做不出來。」
> - **相關名詞**：CPP、MMP、半間距、CD
> - **常見混淆**：Pitch 是「線寬加間隔」，CD 通常只指線寬本身。Pitch 的一半稱為半間距。

## 為什麼不同公司的「幾奈米」不能直接比

節點名稱沒有統一的標準，每家公司都用自己的方式命名。名稱相同的製程，密度可能差很多；名稱數字較大的製程，密度也可能反而更高。

原因有三個：

- **定義不同**：有的看密度，有的看效能，有的看微影能做到多細
- **版本不同**：同一個世代通常會推出效能加強版、低功耗版、低成本版
- **計算方式不同**：密度要用哪一層、哪一種間距去算，公開資料常常沒說清楚

所以看到「A 家的 5 奈米比 B 家的 7 奈米好」，先別急著相信。

要嘛找到同一種量測口徑的數字，要嘛就承認這兩者不能直接比。

這也解釋了一個現象：**節點名稱在商業上比在工程上重要**。對採購與行銷，它是一個好記的標籤；對製程工程師，真正有意義的是那張指標表。

同樣一個數字，不同的人讀出來的東西完全不同。

### 節點名稱是給誰看的

- **採購與合約**：它是一個規格，寫在訂單上，用來界定「這批貨是哪一代」
- **行銷**：它是一個標籤，數字越小聽起來越先進
- **設計者**：它是一個索引，真正的內容在 PDK 與設計規則裡
- **製程工程師**：它幾乎沒有用，看的是間距、密度與良率

## 微縮不只靠製程

近年的微縮，很大一部分來自**設計與製程的共同最佳化**（DTCO）。例如重新設計標準元件的排列方式、減少每個元件需要的金屬導線軌道數，在製程尺寸沒有縮小太多的情況下，也能讓晶片面積變小。

標準單元高度就是一個好例子。同樣的製程，把單元從九條軌道壓到六條，面積立刻少一截；代價是每一條走線的空間變窄，佈線更難、驅動能力也更小。

所以 DTCO 不是「免費的面積」，它也是拿效能與設計自由度去換的。

換句話說，**微縮有一半是設計師讓出來的**。製程端把間距縮小一點，設計端把排列擠緊一點，兩邊加起來才是新聞上看到的面積數字。

晶圓廠會提供設計者一套資料，包括必須遵守的**設計規則**和電晶體的電性模型，稱為 **PDK**（Process Design Kit）。設計者依照 PDK 設計，才能確保晶片做得出來，而且符合預期。

PDK 裡還藏著一個成本：**設計遷移**。把一個產品從舊節點搬到新節點，不是改一個參數就好，整個電路要重新模擬、重新佈局、重新驗證、重新做光罩。

對出貨量不大的產品，這筆錢往往比省下來的面積更貴。

還有一條路是把大晶片拆成幾顆小晶片（Chiplet），用先進封裝接起來。小晶片的良率高得多，成本反而下降；代價是接合、測試與供電都變複雜，見[第 21 章](../../5-backend/21-advanced-packaging/README.md)。這條路不需要微影進步，卻能達到「每顆電晶體更便宜」的效果。

> [!TIP]
> **🔧 Know-how｜比較製程時，看密度和間距，不看名字**
>
> - **情境**：新聞說某家的「N 奈米」打敗另一家的「M 奈米」。
> - **做法**：比較電晶體密度、閘極間距、金屬間距、SRAM 面積，以及在相同條件下的效能與功耗。
> - **為什麼**：節點名稱沒有統一定義，只看數字容易被誤導。
> - **沒做會怎樣**：得出錯誤的結論，例如以為數字小的製程一定比較密、比較好。

## 成熟製程一樣重要

最先進的製程雖然最受矚目，但世界上大量的晶片仍然使用二十多奈米以上的**成熟製程**，例如汽車電子、電源管理、微控制器、感測器和顯示器驅動晶片。

成熟製程之所以撐得久，是因為很多電路根本不需要那麼小：

- 電源管理要處理高電壓與大電流，元件必須夠大
- 類比電路重視匹配與雜訊，縮小反而更難做
- 汽車與工業產品要的是長期供貨與可靠度，不是最新世代
- 感測器與顯示驅動的面積由物理尺寸決定，微縮幫助有限

對這些產品來說，成熟製程的價值是**便宜、穩定、生態完整**：模型、IP、封裝、測試都已經驗證過很多年，換世代反而是風險。

以產能計算，成熟製程占全球晶圓產能的很大一部分。它們的競爭不在微縮，而在成本、良率與供貨穩定度——誰能把每片成本壓低、把交期守住，誰就贏。

> [!TIP]
> **🔧 Know-how｜不是每顆晶片都需要最先進的製程**
>
> - **情境**：一個新產品要決定使用哪一代製程。
> - **做法**：依照效能需求、成本、產量、類比或高電壓的需求來選擇，而不是一味追求最新世代。
> - **為什麼**：先進製程的光罩和設計成本非常高，只有銷量大、對效能要求高的產品才划算。很多類比和高電壓電路在成熟製程上反而表現更好，可靠度也經過長期驗證。
> - **沒做會怎樣**：產品成本過高而失去競爭力，或者無法滿足類比、耐壓與可靠度的需求。
> - **相關章節**：[第 22 章 最終測試與可靠度](../../5-backend/22-final-test-and-reliability/README.md)

## 一個世代要花多少錢

「幾奈米」不只是技術問題，也是一筆很大的帳。一個新世代要成立，得同時湊到四筆錢：

| 項目 | 量級 | 特性 |
|---|---|---|
| 建廠 | 先進節點以百億美元計，成熟節點以十億美元計 | 前期一次投入，靠折舊攤提 |
| 研發 | 一個先進世代以十億美元計 | 要在量產前好幾年就開始燒 |
| 光罩 | 一套先進光罩可以到千萬美元級 | 每次改版就要重做一套 |
| 設計 | 複雜晶片的設計以億美元計 | 由產品公司負擔，成敗自負 |

把這四筆加起來，就會得到一個很現實的結論：**只有出貨量夠大的產品，才養得起先進節點。**

這四筆錢裡，建廠那一筆最重，因為它不管產能利用率幾成都要攤提。這也是為什麼先進節點的產能，總是先被大客戶包走。

一顆晶片如果一年只賣幾萬顆，光罩與設計的成本攤下去，每顆的單價會高到沒有市場。

反過來，手機或伺服器處理器一年出貨上億顆，攤提之後就很划算。這就是「量大者得先進節點」的由來。

這也是為什麼先進節點最後只剩下少數幾種產品在用：手機、處理器、加速器、以及少數特殊應用。

其餘的市場，仍然留在成熟節點。

> [!TIP]
> **🔧 Know-how｜什麼時候該換到下一個節點**
>
> - **情境**：產品下一代要不要跟著換世代。
> - **做法**：算三筆帳：換世代能省下的面積與功耗、要多付的光罩與設計費、以及良率爬坡期間的損失。
> - **為什麼**：新節點早期的良率與產能都不穩，前幾批貨的成本往往比舊節點還高。
> - **沒做會怎樣**：為了「用最新製程」而換世代，結果成本上升、交期拉長，產品反而賣不動。
> - **相關章節**：[第 16 章 良率分析](../../4-yield-and-quality/16-yield-analysis/README.md)

## 常見的誤讀

下面這些誤讀，在新聞與產品說明裡出現的頻率很高。它們的共同點是：把一個商業標籤當成了工程事實。

| 誤讀 | 事實 | 後果 |
|---|---|---|
| 把節點名稱當成結構尺寸 | 3 奈米世代沒有任何結構是 3 奈米寬 | 對技術的理解整個偏掉 |
| 用節點名稱比較兩家密度 | 命名沒有統一定義 | 得到相反的結論 |
| 只看邏輯密度，不看 SRAM | SRAM 常是真正的瓶頸 | 低估晶片面積與成本 |
| 忽略標準單元高度 | 同樣製程，單元高度不同面積差很多 | 晶片尺寸估算失準 |
| 把記憶體世代代號當邏輯節點 | 1α、1β 是記憶體自己的命名 | 兩者不能換算 |
| 以為埃數是新技術 | 只是換一個單位說同一個世代 | 誤判技術差距 |
| 以為新節點一定更便宜 | 光罩、設計、良率爬坡都要算 | 產品成本失控 |
| 忽略供貨與產能 | 新節點產能常被大客戶佔滿 | 交期延誤 |

## 本章重點

1. 「幾奈米」是世代名稱，不是晶片上任何結構的實際尺寸。
2. 早期節點名稱對應實際尺寸，後來逐漸脫鉤；0.7 倍的由來是「面積砍半、晶粒數加倍」。
3. 比較製程應該看閘極間距、金屬間距、電晶體密度、SRAM 面積與標準單元高度。
4. 微縮也靠設計與製程的共同最佳化，PDK 是兩者之間的橋樑；設計遷移本身也是一筆成本。
5. 成熟製程仍然支撐著大量的晶片產品；先進節點則是只有出貨量夠大的產品才養得起。
