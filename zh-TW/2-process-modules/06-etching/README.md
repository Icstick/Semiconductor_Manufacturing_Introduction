## 蝕刻在做什麼

微影完成後，電路圖形只存在於光阻上。**蝕刻**的任務，是把這個圖形「轉印」到底下的材料：被光阻蓋住的地方受到保護，沒有被蓋住的地方就被去除。

可以想像在玻璃上貼一張鏤空的貼紙，再用噴砂把沒有被貼住的地方磨掉。撕掉貼紙後，圖案就留在玻璃上了。光阻就是那張貼紙。

蝕刻和微影最大的差別，是它做的是**減法**。

沉積是把材料加上去，微影是畫出位置，蝕刻才是真的把東西拿走。

拿走這件事有個麻煩：拿多了補不回來，拿少了可以再拿，但再拿的那一次會連旁邊一起動到。

所以蝕刻要同時滿足兩個條件：**挖到該挖的深度就停**，以及**側壁要直**。

少了第一個，會挖穿底下不該動的層；少了第二個，圖形會比微影定義的還寬，等於把微影辛辛苦苦做出來的尺寸還回去一部分。

## 濕蝕刻與乾蝕刻

**濕蝕刻**是把晶圓泡在化學溶液中，讓溶液溶掉材料，例如用氫氟酸溶掉氧化矽。

濕蝕刻往各個方向的速度都差不多，會從側面往光阻底下「吃」進去，所以不適合做很細的圖形，通常用在去除整層材料或清洗。

側蝕的量大致和蝕刻深度相當——挖多深，就往旁邊吃多寬。

等向不是永遠的缺點。要從側面把材料清掉，例如把犧牲層挖掉、讓結構懸空，就需要等向蝕刻；有些流程還會刻意用等向蝕刻把線寬再修細一點，補微影做不到的尺寸。

圖形寬度只有幾十奈米的時候，這個「一樣寬」的側蝕就足以把整條線吃垮，所以先進製程的圖形幾乎不走濕蝕刻。

**乾蝕刻**則是用**電漿**來蝕刻。帶電的離子被電場加速，幾乎垂直地撞向晶圓，所以主要往下挖，可以做出筆直的側壁。現代晶片的細微圖形，幾乎都靠乾蝕刻完成。

| 項目 | 濕蝕刻 | 乾蝕刻 |
|---|---|---|
| 方向性 | 等向，各方向一樣快 | 可以做到幾乎垂直 |
| 速率 | 快，一分鐘數微米 | 慢一些，一分鐘數百奈米 |
| 選擇比 | 靠藥液化學，通常很高 | 靠氣體與條件，可以調 |
| 遮罩 | 光阻常撐不住藥液 | 光阻、氧化物、氮化物都能當 |
| 深寬比 | 高深寬比會彎曲、黏在一起 | 可以做到數十以上 |
| 成本 | 藥液與廢液處理 | 設備、氣體、零件、電力 |
| 常見用途 | 整層去除、清洗、犧牲層 | 圖形定義 |

<!-- 圖：等向蝕刻與非等向蝕刻的剖面對照（側壁形狀、光阻下方的側蝕） -->

> [!NOTE]
> **📖 名詞｜等向與非等向（Isotropic / Anisotropic）**
>
> - **定義**：等向蝕刻往各方向的速度相同；非等向蝕刻主要往單一方向（通常是往下）進行。
> - **現場用法**：「這道要非等向，側壁要直。」
> - **相關名詞**：乾蝕刻、濕蝕刻、側蝕、輪廓
> - **常見混淆**：乾蝕刻不一定都是非等向。有些乾蝕刻會刻意調成等向，用來從側面去除材料，結果取決於製程條件。

## 原理：為什麼乾蝕刻能往下挖

電漿裡同時有兩種東西在做事，一件是**化學**，一件是**物理**。

化學的那一半是自由基：非常活潑的原子團，碰到材料就反應，生成氣體被抽走。它不挑方向，哪裡碰到就吃哪裡，所以單靠化學，結果一定是等向的。

物理的那一半是離子：被電場加速，垂直打到晶圓上。它的作用是「撞」——把表面的原子鍵結打斷，讓後面的化學反應容易得多。單靠物理也能把材料打掉，但那是什麼都打，選擇比等於一，遮罩會和目標材料一起被削掉。

乾蝕刻之所以能又直又準，是因為兩件事**同時**發生：離子只打到水平面上，被它打過的地方，化學反應快了好幾倍；側壁幾乎沒有被離子打到，化學反應就慢。於是「垂直方向快、水平方向慢」，形狀就出來了。

這個機制叫**反應式離子蝕刻**（Reactive Ion Etching，RIE），是現代蝕刻的基礎。

只有這樣還不夠。側壁雖然慢，還是會被自由基慢慢啃。

所以多數蝕刻會刻意讓氣體在側壁留下一層**聚合物**，像在牆上刷一層保護漆，把化學反應擋住；同時用離子把底部的聚合物打掉。保護太多，孔口會越來越窄、最後夾斷；保護太少，側壁會被咬出弧形。工程師調的其實就是這個平衡。

> [!NOTE]
> **📖 名詞｜鞘層（Sheath）**
>
> - **定義**：電漿和晶圓（或腔壁）之間一層很薄的強電場區，離子一通過這裡就被加速。
> - **現場用法**：「這道鞘層太厚，離子能量太高，選擇比會掉。」
> - **相關名詞**：偏壓、離子能量、離子密度、方向性
> - **常見混淆**：鞘層不是「電漿的一層」。它是電漿和固體交界處形成的電位差區域，厚度隨壓力和功率改變。

離子能不能筆直地走，取決於它在路上會不會撞到別的分子。腔體壓力越低，氣體越稀薄，離子從鞘層到晶圓的途中越不會被撞歪，方向性越好；壓力一高，離子東撞西撞，進到孔裡的角度就散了，側壁開始被斜著打，形狀就走鐘。

這是為什麼乾蝕刻幾乎都在低壓下操作。

## 電漿：蝕刻的工具

**電漿**是氣體被高能量激發後的狀態，裡面混合了離子、電子和非常活潑的原子團，常被稱為物質的第四態。

蝕刻機台在真空腔體中通入特定氣體，再用射頻電力把它變成電漿，腔體裡會發出微弱的光。

電漿中的活潑原子團負責和材料發生化學反應，離子則負責提供方向，兩者合作，才能又快又準地往下挖。

那道光是副產品，也是資訊。

氣體被激發後回到低能態會發光，不同成分發出的波長不一樣；工程師盯著某幾個波長看，就知道腔體裡的化學正在怎麼變——這就是後面終點偵測的原理。

機台裡有幾個關鍵部位：把氣體均勻灑進來的噴頭、承載晶圓並施加偏壓的電極、把晶圓吸住並控溫的靜電吸盤、以及把廢氣抽走的真空泵。

射頻功率主要決定「有多少離子」，偏壓主要決定「離子有多快」；這兩件事分開調，工程師才有辦法在蝕刻率和選擇比之間找平衡。

## 蝕刻要看哪些指標

- **蝕刻率**：每分鐘可以挖多深。
- **均勻度**：晶圓上不同位置挖得是否一樣。
- **選擇比**：要挖的材料和不想挖的材料，蝕刻速度差多少。
- **輪廓**：側壁是不是筆直，有沒有往內縮或往外凸。
- **CD 變化**：蝕刻後的線寬和微影後相比，變了多少。

這五項各自對應一種「後面會出事」的方式：

| 指標 | 看什麼 | 超規之後誰受害 |
|---|---|---|
| 蝕刻率 | 每分鐘挖多深 | 產能，以及過度蝕刻的時間預算 |
| 均勻度 | 片內與片間之間的差異 | 線寬分布、深度分布，良率變成地圖上的圖案 |
| 選擇比 | 目標材料對其他材料的速率比 | 停止層被吃穿，傷到底下的元件 |
| 輪廓 | 側壁角、有沒有內縮或外凸 | 後續填入留下空隙，電阻與可靠度 |
| CD 變化 | 蝕刻前後的線寬差 | 電晶體的速度與漏電 |
| 殘留與微粒 | 該挖的挖乾淨了沒 | 斷路、短路、接觸不良 |

> [!NOTE]
> **📖 名詞｜選擇比（Selectivity）**
>
> - **定義**：目標材料的蝕刻速度，和其他材料蝕刻速度的比值。選擇比越高，越能只挖想挖的材料。
> - **現場用法**：「這道對氮化矽的選擇比不夠，停止層被吃穿了。」
> - **相關名詞**：蝕刻停止層、過度蝕刻、光阻消耗
> - **常見混淆**：講選擇比時一定要說清楚是「對什麼材料」。對光阻的選擇比和對下層材料的選擇比，是兩個不同的數字。

## 怎麼知道什麼時候該停

蝕刻挖穿目標材料、碰到下一層時，電漿中的化學成分會改變，發出的光的顏色和強度也跟著改變。

機台持續監測這個光，就能判斷什麼時候挖到底了，這叫做**終點偵測**（Endpoint Detection）。

實際做法是挑一個只屬於目標材料的波長，盯著它的亮度。挖到下一層，那個訊號會突然掉下去或跳上來。

訊號好不好看，取決於開口面積：圖形密、開的口大，訊號清楚；開的口很小，訊號只在一大片背景裡微微變動，就得靠更長的取樣或更靈敏的演算法。

到達終點後，通常還會再多蝕刻一點點，確保整片晶圓上的材料都清乾淨，這叫**過度蝕刻**（Over Etch）。

挖不夠會留下殘留，挖太多則會傷到下層。

多蝕刻的那一段，通常是一到三成的額外時間。

這個比例不是隨便定的：晶圓中心與邊緣的速率本來就有差，圖形密的地方和疏的地方也不一樣，過度蝕刻就是在「補這些差異」。所以選擇比不夠的時候，先撐不住的不是終點，是那一段多出來的時間。

## 蝕刻之後

蝕刻完成後，先用氧電漿把光阻燒掉，稱為**去光阻**（Ashing 或 Strip），再經過清洗，接著量測線寬和缺陷，這個檢查稱為 **AEI**（After Etch Inspection）。

去光阻看起來只是「把不要的東西清掉」，其實有兩件事要一起處理。

一件是光阻本身，氧電漿把它燒成氣體；另一件是蝕刻時留在側壁和底部的聚合物，那些東西不是有機物，氧電漿燒不掉，要靠濕式藥液。

只做乾式、不做濕式，聚合物會留到下一站變成缺陷。

蝕刻也是整條線的咽喉。它的深度決定 CMP 要磨掉多少——挖得太深，CMP 為了磨平得吃更多，連不該磨的地方都磨掉；挖得太淺，後面的金屬填不滿。它的側壁形狀決定薄膜蓋不蓋得住，而薄膜蓋不住，佈植就會從縫裡鑽進去。這些帳通常要到電性測試才結算。

AEI 量到的線寬，會和微影量到的線寬相比；兩者的差就是蝕刻加上去的部分。這個數字回到微影，成為下一批曝光條件的修正依據——這是兩站之間每天在做的一次對帳。

和微影不同，蝕刻做壞了通常無法重來，因為材料已經被挖掉了。

而且蝕刻會在表面留下一層被離子打傷的薄層，結構已經不是原本的樣子；這層損傷要在後面的步驟裡想辦法處理，處理不掉就會變成漏電或接觸電阻。

## 越挖越深：高深寬比蝕刻

記憶體等產品需要挖出非常深又非常窄的孔，深度可以是寬度的數十倍。孔越深，離子越難抵達底部，蝕刻速度會變慢，孔也可能變彎、扭曲，或是中段被挖得比較寬。這是目前最困難的製程之一，見[第 13 章](../../3-integration/13-memory/README.md)。

愈深愈難，背後有三個原因。

第一是**傳輸**：反應氣體要進得去、副產物要出得來，孔越深越難交換，底部自然長得慢。第二是**角度**：離子不可能百分之百垂直，總有一點發散，走進深孔後，稍微斜一點的離子就打到側壁，把孔挖成弧形。第三是**帶電**：絕緣的遮罩和側壁會累積電荷，把後來的離子推偏，孔底就開始歪。

這三件事加起來，就是高深寬比蝕刻的難處：同一個孔，上段、中段、下段的形狀可能都不一樣。

工程師的對策是把條件拆開——分段改變氣體比例、用脈衝的方式供電讓電荷有時間散掉、在側壁重新補一層保護。做得好的時候，一個孔從頭到底的直徑差異可以控制在很小的範圍；做不好的時候，孔底會歪到接不上下一層。

## 蝕刻的帳單：產能、成本與壽命

蝕刻是單片製程，一片一片進腔體，所以產能直接被「一片多久」鎖住。

乾蝕刻的速率大約每分鐘數百奈米，一片晶圓要挖的深度從幾十奈米到幾微米，換算下來一片一到三分鐘。

機台通常有好幾個腔體並行，同一批晶圓分散進去，一小時處理數十片是常見的量級。

| 成本項目 | 內容 | 特性 |
|---|---|---|
| 設備折舊 | 蝕刻機、真空泵、射頻電源 | 固定成本，開不開機都在燒 |
| 氣體 | 含氟、含氯的反應氣體，加上氬氣與氧氣 | 變動成本，部分氣體單價高 |
| 零件 | 腔體襯裡、電極、遮罩環、靜電吸盤 | 消耗品，數百到數千片換一次 |
| 保養停機 | 定期清腔、更換零件、重新建立腔體狀態 | 不生產，但折舊與人力照算 |
| 電力與尾氣 | 射頻功率、真空泵、廢氣處理 | 單片式機台耗電高 |

氣體那一項值得多說一句。含氟的蝕刻氣體有些暖化潛勢極高，排放法規管得緊，所以機台後面通常接著燃燒或電漿式的尾氣處理設備，把殘餘氣體分解掉。這套設備的購置與運轉費用，最後也會攤到每一片上。

零件壽命是另一個容易被低估的項目。

電漿會侵蝕腔體內壁，工程師會在裡面放可更換的襯裡，讓它替腔壁擋著；襯裡被吃掉就要換，換完還要重新建立穩定的表面狀態。所以蝕刻的成本不是「氣體加電力」，而是「氣體加零件加停機」。

> [!TIP]
> **🔧 Know-how｜清潔完的腔體要先「養」一下**
>
> - **情境**：蝕刻腔體剛做完保養，內壁被清潔得乾乾淨淨。
> - **做法**：先跑一些擋片，讓腔體內壁蓋上一層穩定的沉積物，再開始跑產品。這個步驟現場叫 **Seasoning**。
> - **為什麼**：電漿會和腔體內壁互相作用。內壁的狀態不同，電漿的成分就不同，蝕刻率也會跟著變。
> - **沒做會怎樣**：保養後的前幾批晶圓蝕刻結果偏移，可能造成線寬或深度異常。
> - **相關章節**：[第 1 章 晶圓廠如何運作](../../0-before-you-start/01-how-a-fab-works/README.md)

> [!TIP]
> **🔧 Know-how｜同一台機台，不同腔體也要比對**
>
> - **情境**：一台蝕刻機通常有好幾個腔體，同一批晶圓會分散到不同腔體處理。
> - **做法**：工程師會定期比對各腔體的結果，讓它們盡量一致，系統也會記錄每片晶圓是在哪個腔體做的。
> - **為什麼**：腔體之間的微小差異，會讓晶圓之間出現系統性的差異。
> - **沒做會怎樣**：同一批晶圓中有幾片表現特別差，卻查不出原因。有腔體紀錄，才能找出「問題都出在同一個腔體」。
> - **相關章節**：[第 16 章 良率與故障分析](../../4-yield-and-quality/16-yield-analysis/README.md)

> [!TIP]
> **🔧 Know-how｜光阻不是無敵的**
>
> - **情境**：微影留下的光阻，要在蝕刻時當遮罩用。
> - **做法**：工程師會估算這道蝕刻會消耗掉多少光阻，回頭要求微影把光阻塗到足夠的厚度，並在蝕刻條件上控制對光阻的選擇比。
> - **為什麼**：光阻是有機物，會被離子和自由基一起侵蝕；蝕刻越久、功率越高，光阻掉得越快。
> - **沒做會怎樣**：圖形在蝕刻中途失去遮罩，邊緣被啃掉，CD 變寬或圖形直接消失。
> - **相關章節**：[第 4 章 微影](../../2-process-modules/04-lithography/README.md)

## 常見異常

| 異常 | 可能原因 | 結果 |
|---|---|---|
| 蝕刻不足 | 時間或功率不足、終點判斷錯誤 | 殘留材料，造成斷路 |
| 過度蝕刻 | 選擇比不足、時間太長 | 傷到下層材料 |
| CD 偏移 | 側壁輪廓改變、光阻消耗太多 | 線寬不合格 |
| 微粒 | 腔體內壁的沉積物剝落 | 缺陷、短路 |
| 負載效應 | 圖形密的地方和疏的地方蝕刻速度不同 | 同一顆晶粒內深度不一致 |
| 側壁彎曲 | 離子散射、側壁保護不足 | 後續填入留下空隙 |
| 孔底傾斜或扭曲 | 深孔中電荷累積、遮罩不平 | 上下層接不上 |
| 微遮罩 | 顆粒或聚合物碎屑落在表面 | 局部挖不下去，留下柱狀殘留 |
| 電荷損傷 | 電漿不均、電荷無處可去 | 閘極絕緣層受損、漏電變大 |

## 本章重點

1. 蝕刻把光阻上的圖形轉印到底下的材料上，是減法製程，做壞了補不回來。
2. 濕蝕刻是等向的，乾蝕刻用電漿可以做到非等向，現代細微圖形主要靠乾蝕刻。
3. 方向性來自離子，化學反應來自自由基，側壁靠聚合物保護，三者平衡才有筆直的側壁。
4. 選擇比決定能不能「只挖想挖的材料」；終點偵測透過電漿發出的光，判斷什麼時候該停。
5. 深寬比一高，傳輸、角度與帶電三個問題同時出現，形狀很難從頭到尾一致。
6. 蝕刻做壞通常無法重來，所以腔體狀態、零件壽命與保養節奏的管理特別重要。
