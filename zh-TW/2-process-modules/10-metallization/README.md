## 把數十億個電晶體連起來

電晶體做好之後，還要用金屬導線把它們連成電路。一顆先進晶片上有數十億個電晶體，一層導線根本不夠用，所以導線會疊成好幾層，先進晶片甚至超過十層。

這些導線很像城市的道路系統：

- **下層**：又細又密，像巷弄，負責連接鄰近的電晶體。
- **中層**：較寬，像市區道路，連接不同的電路區塊。
- **上層**：最粗最寬，像高速公路，負責長距離傳送訊號和供應電源。

<!-- 圖：多層金屬導線剖面（下層細密、上層粗寬，層與層之間以導通孔連接） -->

為什麼要分層？因為訊號走的路越長，電阻和電容造成的延遲就越大。同一層裡，能擠多細就多細（省面積）；但跨越整顆晶片的長距離連線，需要粗線才不會太慢。

所以越上層做越粗，是「延遲」和「密度」兩個需求互相妥協的結果。

供電用的那一層又更粗，因為它要扛的是整顆晶片的電流——一條細線扛大電流，不只是變慢，會直接燒斷。

這裡還有一個比較少人注意的成本邏輯：**上層的線寬大，微影的解析度要求就低，可以用比較成熟、比較便宜的光源來做。** 一個產品不是每一層都值得用最先進的微影——通常只有最下面幾層最細的線才需要。這也是為什麼金屬層數一多，成本不會等比例上升。

## 接觸窗與導通孔

電晶體和第一層金屬之間，隔著一層絕緣層。要讓它們連通，先在絕緣層上挖出小孔，再填入金屬，這些小孔叫做**接觸窗**（Contact）。接觸窗通常填的是**鎢**，因為鎢能用 CVD 把又小又深的孔填滿，填完再用 CMP 把多餘的鎢磨掉。

金屬層與金屬層之間的連接孔，則叫做**導通孔**（Via）。

為什麼是鎢，而不是銅或鋁？

- **耐高溫**：接觸窗做好之後，後面還有高溫的退火和薄膜步驟。鋁的熔點大約 660 °C，在這個溫度附近就會軟化；鎢的熔點超過 3,400 °C，幾乎不受影響。
- **填得進去**：CVD 是氣體在表面反應，氣體可以鑽進很深的孔，所以保形性好。PVD 是直線前進的，孔越深，底部的膜越薄，容易留下空洞。
- **不會和矽直接反應**：鎢和矽之間通常會墊一層阻障層，避免兩者接觸後形成不必要的化合物。

> [!NOTE]
> **📖 名詞｜接觸窗與導通孔（Contact / Via）**
>
> - **定義**：接觸窗連接電晶體和第一層金屬；導通孔連接上下兩層金屬。
> - **現場用法**：「這顆 Via 開不通」，意思是導通孔沒有接好，形成斷路。
> - **相關名詞**：鎢栓塞、阻障層、Via Chain
> - **常見混淆**：兩者都是「填滿金屬的孔」，差別在連接的位置：接觸窗在電晶體上方，導通孔在金屬層之間。

工程師常說「Via Chain」，指的是一串串串起來的導通孔測試結構。

為什麼要測一串而不是一個？因為單一顆導通孔的電阻太小，量不準；串個幾百幾千顆，電阻加起來才量得到。

而且一串裡只要有一顆斷了，整串就開路——這是用統計抓單點失效的典型做法，見[第 19 章 晶圓測試](../../5-backend/19-wafer-test/README.md)。

## 從鋁到銅

早期的導線使用**鋁**：先用 PVD 把鋁鋪滿整片晶圓，再用微影和蝕刻把不要的鋁去掉，留下導線。

鋁的優點是「好做」：它可以被蝕刻，所以只要鋪一層、蓋光阻、曝光、蝕刻，導線就出來了。缺點是兩個：電阻不夠低，而且怕電遷移。

- **電阻不夠低**：鋁的電阻率大約是銅的 1.6 倍。
- **怕電遷移**：電流長時間流過時，電子會把鋁原子一點一點推走，最後留下空洞、斷線。這個現象叫**電遷移**（Electromigration），是鋁導線壽命的頭號殺手。產業後來在鋁裡加入少量的銅來改善，但仍然有極限。

1990 年代末期，產業開始改用**銅**。銅的電阻比鋁低，比較不容易因為長期通電而損壞。

具體一點：銅的電阻率大約 1.7 微歐姆·公分，鋁大約 2.7——差了將近四成。在先進節點，這個差距足以決定一顆晶片能不能跑到目標頻率。

但銅有一個大問題：很難用乾蝕刻挖出圖形。於是產業改用一種完全相反的做法：**先挖溝，再填銅**。

---

## 原理：為什麼銅不能像鋁那樣蝕刻

要理解這件事，得先知道蝕刻是怎麼把材料「帶走」的。

蝕刻不是把材料溶掉，而是讓它變成**氣體**被抽走。電漿裡的活性離子打在表面，和材料反應生成一種揮發性的化合物，這個化合物在腔體的壓力和溫度下是氣態，於是被真空泵抽走。整個過程是「固體 → 氣體」，中間不經過液體。

鋁可以這樣做，因為鋁的氯化物揮發性很好——它在蝕刻的溫度下就會變成氣體離開表面。

銅不行。銅的氯化物要到接近一千度才沸騰，而製程腔體只有一兩百度。它會留在表面，形成一層渣，把下面的銅擋住。你越蝕刻，表面堆的渣越厚，反應就越慢，最後停住。

產業試過其他方法：用不同的氣體、提高溫度、用物理性的濺射把銅打掉。

每一種都有問題——溫度太高會傷到已經做好的元件；純物理濺射的選擇比很差，該留的也一起被打掉；而且打下來的銅會重新沉積在別的地方。

最後的答案不是「找到一種能蝕刻銅的方法」，而是**換一個順序**：

- 鋁的做法是「**加法再減法**」：先鋪一整片金屬，再把不要的蝕刻掉。
- 銅的做法是「**減法再加法**」：先在絕緣層挖出溝，再把銅填進去，最後把溢出溝外的銅磨掉。

這個順序反轉，是後段製程幾十年來最大的一次方法論改變。它把「定義圖形」交給了微影和蝕刻的組合（挖溝），把「去除多餘材料」交給了 CMP。

換句話說，**銅製程把第 6 章的蝕刻和第 8 章的 CMP 綁在了一起**，任何一邊不穩，另一邊都會受害。

## 大馬士革製程

這種做法的名字來自古代大馬士革的鑲嵌技法：在器物表面刻出凹槽，填入金屬，再把表面磨平。銅導線的做法幾乎一模一樣：

**鋪絕緣層 → 挖出導通孔和溝槽 → 鋪阻障層與晶種層 → 電鍍銅 → 退火 → 銅 CMP → 鋪覆蓋層**

1. **鋪絕緣層**：用 CVD 鋪上一層絕緣材料。
2. **挖洞**：用微影和蝕刻挖出導通孔和導線溝槽。
3. **阻障層與晶種層**：先鋪一層極薄的阻障層，防止銅擴散出去；再鋪一層薄薄的銅，作為電鍍的起點。
4. **電鍍銅**：把晶圓放進電鍍液，讓銅填滿孔洞和溝槽。
5. **退火**：加熱讓銅的結構穩定下來。
6. **銅 CMP**：把溝槽以外多餘的銅磨掉。
7. **鋪覆蓋層**：在銅的表面蓋上一層薄薄的覆蓋層，防止銅氧化或擴散。

<!-- 圖：雙大馬士革流程剖面（挖洞 → 阻障層 → 電鍍 → CMP → 覆蓋層） -->

每一步都有它不能省的理由。

**阻障層**通常是幾奈米厚的金屬氮化物。它的作用是擋住銅——銅在矽和氧化層裡擴散很快，一旦跑到電晶體裡就是災難。但阻障層本身的電阻比銅高，所以它越薄越好，又不能薄到有破洞。

**晶種層**是薄薄一層銅。電鍍需要導電的表面，如果直接在一片絕緣的阻障層上電鍍，電流沒有路可走。晶種層就是那條路。

**退火**是為了讓電鍍出來的銅晶粒長大。剛鍍上去的銅晶粒很細、缺陷很多，電阻偏高；加熱之後晶粒合併、電阻下降，應力也釋放掉。

如果導通孔和溝槽一起填銅，就稱為**雙大馬士革**（Dual Damascene），可以少做一次填充和研磨。做法上可以「先挖通孔再挖溝槽」，也可以反過來——兩種順序各有各的對準難題。

每一層金屬都重複這個流程，一層一層往上蓋。

> [!NOTE]
> **📖 名詞｜大馬士革製程（Damascene）**
>
> - **定義**：先在絕緣層挖出溝槽，填入金屬，再用 CMP 磨掉多餘部分的導線製作方法。
> - **現場用法**：「這幾層是銅的雙大馬士革。」
> - **相關名詞**：電鍍、阻障層、晶種層、銅 CMP
> - **常見混淆**：鋁導線是「先鋪金屬再蝕刻」，銅導線是「先挖溝再填金屬」，兩者順序剛好相反。

> [!NOTE]
> **📖 名詞｜阻障層與晶種層（Barrier / Seed Layer）**
>
> - **定義**：阻障層是擋在銅和絕緣層之間的一層薄膜，防止銅擴散；晶種層是電鍍前鋪的薄銅，提供導電的起點。
> - **現場用法**：「這層的 barrier 太薄，漏電偏高。」
> - **相關名詞**：電鍍、銅擴散、附著層
> - **常見混淆**：阻障層不是絕緣層——它必須導電，否則電流到不了銅；它擋的是原子的擴散，不是電子。

> [!TIP]
> **🔧 Know-how｜電鍍銅要從底部往上填**
>
> - **情境**：要把又窄又深的溝槽完全填滿銅。
> - **做法**：電鍍液中會加入特殊的添加劑，讓孔洞底部的銅長得比開口處快，由下往上填滿。
> - **為什麼**：如果開口處的銅長得比較快，開口會先被封住。
> - **沒做會怎樣**：導線內部留下空洞，電阻變高，長期使用時也更容易斷線。
> - **相關章節**：[第 5 章 薄膜](../../2-process-modules/05-thin-films/README.md)

「由下往上填」靠的是幾種添加劑的競爭：有的抑制表面沉積、有的加速底部沉積、有的讓開口處的銅被整平。它們在溝槽不同深度的濃度不一樣，於是自動形成「底部快、開口慢」的結果。工程師能做的是調整添加劑的組成和電流的方式，讓這個過程發生在正確的尺寸上——但溝槽一變窄、深寬比一變高，窗口就變窄。

## 低介電常數材料

導線之間隔著絕緣層，兩條靠得很近的導線就像一個小電容，會拖慢訊號、增加耗電。為了減少這個影響，先進製程使用**低介電常數材料**（Low-k）作為導線之間的絕緣層。

這個電容有多大影響？訊號在導線上跑得多快，取決於電阻和電容這兩個因素——線越細電阻越大，線越近電容越大，兩者同時在惡化。

所以後段製程的進步是兩條腿走路：**用銅降電阻，用低介電常數材料降電容。**

二氧化矽的介電常數大約是 4。產業一路把它往下壓：先摻入氟或碳，降到 3 上下。

再做成多孔的結構，把空氣（介電常數接近 1）引進材料裡，可以降到 2.5 以下。

空氣是理論上最好的絕緣體，所以「多孔」是這條路的極限方向。但多孔也帶來麻煩：

- **機械強度變差**：孔洞讓材料變脆，CMP 的壓力、封裝的應力都可能讓它裂開或剝離。
- **吸水性變高**：孔洞會吸附水氣，水的介電常數大約 80，一吸就把低介電的好處抵銷掉。
- **熱傳導變差**：孔洞也隔絕了熱，導線的熱量不容易散出去。

所以低介電常數材料的選擇，從來不是「越低越好」，而是「在可靠度和製程窗口之間找一個還能量產的值」。這也是為什麼這個領域的進展比銅本身慢得多。

## 越來越細的挑戰

導線越做越細，問題也越來越多：

- **電阻變高**：導線太細時，阻障層占的比例變大，電子也更容易被散射，產業正在研究以其他金屬製作最細的導線。
- **電遷移**：電流長時間流過時，會把金屬原子一點一點推走，最後形成空洞而斷線，見[第 22 章 最終測試與可靠度](../../5-backend/22-final-test-and-reliability/README.md)。

這兩個問題其實是同一個問題的兩面：**線越細，表面和界面的占比越大。**

一條線寬 20 奈米的銅線，兩側各有一層幾奈米厚的阻障層，中間真正導電的銅可能只剩一半的截面積。

電子在銅裡走的時候，會不斷撞到晶粒邊界和側壁——線越細，撞到的機會越多，等效電阻率就越高。

這是物理限制，不是「再努力一點」能解決的。所以產業在找替代方案：

- **換材料**：用電阻更低的金屬，或是在銅外面包一層能減少表面散射的材料。
- **換做法**：把最細的幾層改成不用銅的製程，或直接做成氣隙——用空氣當絕緣層，介電常數最低。
- **換方向**：把晶片拆成多顆小晶片，用先進封裝連接，讓每一顆的內連線不用那麼極端，見[第 21 章 先進封裝](../../5-backend/21-advanced-packaging/README.md)。

還有一個容易被忽略的挑戰：**熱**。後段的導線層在晶圓上方，離散熱的矽基板很遠，熱量不容易傳出去；低介電常數材料又是熱的不良導體。所以越先進的晶片，後段的散熱越棘手。

## 一層金屬要花多少步驟、多少錢

一層銅導線不是「一個步驟」，而是十幾個步驟繞一圈：

| 階段 | 大約步驟數 | 內容 |
|---|---|---|
| 介電層 | 2～3 | 鋪絕緣層、平坦化 |
| 圖形 | 3～4 | 微影、蝕刻溝槽與導通孔、去除光阻與殘留 |
| 阻障層與晶種層 | 2 | 濺鍍阻障層、濺鍍晶種層 |
| 填銅 | 2 | 電鍍、退火 |
| 平坦化 | 1～2 | 銅 CMP、清潔 |
| 覆蓋層 | 1 | 鋪保護層 |

把這些乘上層數，就是後段製程的規模：一個有十四、十五層金屬的產品，後段可能有兩百多道步驟。

它占整個流程的一半以上。

這也是為什麼後段在成本和時間上都不比前段輕鬆——它雖然沒有微影那麼貴，但步驟數量和變異來源都更多。

成本結構上，後段有三個大項：

| 成本項目 | 內容 | 特性 |
|---|---|---|
| 微影與蝕刻 | 每一層都要定義圖形 | 變動成本，層數越多越貴 |
| 薄膜與電鍍 | 阻障層、晶種層、銅、介電層 | 變動成本，材料單價高 |
| CMP 與清洗 | 每一層都要磨平、洗淨 | 變動成本，耗材為主 |

這裡有一個關鍵的經濟事實：**後段的成本大致和層數成正比，而前段的成本大致和微影次數成正比。** 所以產業有兩個方向相反的壓力：一方面要更多層來連接更多電晶體，另一方面每一層都在燒錢。

3D 堆疊和先進封裝之所以誘人，一部分原因就是它讓「連接」這件事不必全部靠後段金屬層來做。

## 常見異常

後段製程的指標和異常，可以分成「電性」和「結構」兩類：

| 指標 | 看什麼 | 超規的後果 |
|---|---|---|
| 導線電阻 | 線寬、厚度、阻障層占比 | 延遲變大、速度上不去 |
| 導通孔電阻 | 單顆與 Via Chain 的電阻 | 接觸不良、開路 |
| 漏電 | 導線之間、導線對基板的漏電 | 耗電增加、可靠度下降 |
| 空洞與縫隙 | 填銅是否完全填滿 | 電阻升高、長期斷線 |
| 碟化與殘留 | CMP 後的銅厚度與殘留 | 短路或電阻偏移 |

指標守不住、或結構沒做好，就變成這些異常：

| 異常 | 可能原因 | 結果 |
|---|---|---|
| 銅填充空洞 | 電鍍條件異常、開口太窄 | 電阻變高、可靠度問題 |
| 銅殘留 | CMP 研磨不足 | 導線短路 |
| 導通孔不通 | 蝕刻不足、孔底殘留 | 斷路 |
| 阻障層失效 | 阻障層太薄或不連續 | 銅擴散，造成漏電 |
| 低介電材料損傷 | 蝕刻、CMP 或封裝的應力 | 漏電、結構剝離 |
| 電遷移斷線 | 電流密度過高、晶粒邊界太多 | 長期使用後斷路 |
| 腐蝕 | 銅暴露在空氣或化學品中太久 | 接觸電阻上升 |
| 應力誘發剝離 | 薄膜應力累積、界面附著不良 | 整層剝落，整片報廢 |

> [!TIP]
> **🔧 Know-how｜銅磨完之後不能放太久**
>
> - **情境**：銅 CMP 完成，晶圓表面的銅直接暴露在空氣中。
> - **做法**：CMP 到鋪上覆蓋層之間設有 Q-Time 限制，超過時間要由工程師判斷處理方式。
> - **為什麼**：裸露的銅很容易氧化和腐蝕。
> - **沒做會怎樣**：銅表面劣化，導通孔的接觸電阻變高，可靠度也會下降。
> - **相關章節**：[第 9 章 清洗與污染控制](../../2-process-modules/09-cleaning/README.md)

## 本章重點

1. 晶片用多層金屬導線連接電晶體，下層細密、上層粗寬；上層線寬大，微影反而比較便宜。
2. 接觸窗連接電晶體與第一層金屬，導通孔連接金屬層與金屬層；接觸窗用鎢是因為耐高溫、填得進去。
3. 銅取代鋁的關鍵不是「銅比較好」，而是「銅的氯化物不揮發」，所以只能反過來做：先挖溝、再填銅、再磨平。
4. 大馬士革製程把蝕刻和 CMP 綁在一起；阻障層與晶種層是電鍍能不能成功的兩個前提。
5. 導線越細，表面與界面的占比越大，電阻和電遷移越難處理；低介電材料則是另一個方向的戰場。
