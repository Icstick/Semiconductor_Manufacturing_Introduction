# 第 6 章　刻蚀：照着图形把材料挖掉

> - 下一站：去除光刻胶、清洗，然后测量

## 刻蚀在做什么

光刻完成后，电路图形只存在于光刻胶上。**刻蚀**的任务，是把这个图形「转印」到底下的材料：被光刻胶盖住的地方受到保护，没有被盖住的地方就被去除。

可以想像在玻璃上贴一张镂空的贴纸，再用喷砂把没有被贴住的地方磨掉。撕掉贴纸后，图案就留在玻璃上了。光刻胶就是那张贴纸。

刻蚀和光刻最大的差别，是它做的是**减法**。

沉积是把材料加上去，光刻是画出位置，刻蚀才是真的把东西拿走。

拿走这件事有个麻烦：拿多了补不回来，拿少了可以再拿，但再拿的那一次会连旁边一起动到。

所以刻蚀要同时满足两个条件：**挖到该挖的深度就停**，以及**侧壁要直**。

少了第一个，会挖穿底下不该动的层；少了第二个，图形会比光刻定义的还宽，等于把光刻辛辛苦苦做出来的尺寸还回去一部分。

---

## 湿法刻蚀与干法刻蚀

**湿法刻蚀**是把晶圆泡在化学溶液中，让溶液溶掉材料，例如用氢氟酸溶掉氧化硅。

湿法刻蚀往各个方向的速度都差不多，会从侧面往光刻胶底下「吃」进去，所以不适合做很细的图形，通常用在去除整层材料或清洗。

侧蚀的量大致和刻蚀深度相当——挖多深，就往旁边吃多宽。

各向同性不是永远的缺点。要从侧面把材料清掉，例如把牺牲层挖掉、让结构悬空，各向同性反而是必要的；有些流程还会刻意用各向同性刻蚀把线宽再修细一点，补光刻做不到的尺寸。

图形宽度只有几十纳米的时候，这个「一样宽」的侧蚀就足以把整条线吃垮，所以先进工艺的图形几乎不走湿法刻蚀。

**干法刻蚀**则是用**等离子体**来刻蚀。带电的离子被电场加速，几乎垂直地撞向晶圆，所以主要往下挖，可以做出笔直的侧壁。现代芯片的细微图形，几乎都靠干法刻蚀完成。

| 项目 | 湿法刻蚀 | 干法刻蚀 |
|---|---|---|
| 方向性 | 各向同性，各方向一样快 | 可以做到几乎垂直 |
| 速率 | 快，一分钟数微米 | 慢一些，一分钟数百纳米 |
| 选择比 | 靠药液化学，通常很高 | 靠气体与条件，可以调 |
| 掩模 | 光刻胶常撑不住药液 | 光刻胶、氧化物、氮化物都能当 |
| 深宽比 | 高深宽比会弯曲、黏在一起 | 可以做到数十以上 |
| 成本 | 药液与废液处理 | 设备、气体、零件、电力 |
| 常见用途 | 整层去除、清洗、牺牲层 | 图形定义 |

<!-- 图：各向同性刻蚀与各向异性刻蚀的剖面对照（侧壁形状、光刻胶下方的侧蚀） -->

> [!NOTE]
> **📖 名词｜各向同性与各向异性（Isotropic / Anisotropic）**
>
> - **定义**：各向同性刻蚀往各方向的速度相同；各向异性刻蚀主要往单一方向（通常是往下）进行。
> - **现场用法**：「这道要各向异性，侧壁要直。」
> - **相关名词**：干法刻蚀、湿法刻蚀、侧蚀、轮廓
> - **常见混淆**：干法刻蚀不一定都是各向异性。有些干法刻蚀会刻意调成各向同性，用来从侧面去除材料，结果取决于工艺条件。

## 原理：为什么干法刻蚀能往下挖

等离子体里同时有两种东西在做事，一件是**化学**，一件是**物理**。

化学的那一半是自由基：非常活泼的原子团，碰到材料就反应，生成气体被抽走。它不挑方向，哪里碰到就吃哪里，所以单靠化学，结果一定是各向同性的。

物理的那一半是离子：被电场加速，垂直打到晶圆上。它的作用是「撞」——把表面的原子键结打断，让后面的化学反应容易得多。单靠物理也能把材料打掉，但那是什么都打，选择比等于一，掩模会和目标材料一起被削掉。

干法刻蚀之所以能又直又准，是因为两件事**同时**发生：离子只打到水平面上，被它打过的地方，化学反应快了好几倍；侧壁几乎没有被离子打到，化学反应就慢。于是「垂直方向快、水平方向慢」，形状就出来了。

这个机制叫**反应离子刻蚀**（Reactive Ion Etching，RIE），是现代刻蚀的基础。

只有这样还不够。侧壁虽然慢，还是会被自由基慢慢啃。

所以多数刻蚀会刻意让气体在侧壁留下一层**聚合物**，像在墙上刷一层保护漆，把化学反应挡住；同时用离子把底部的聚合物打掉。保护太多，孔口会越来越窄、最后夹断；保护太少，侧壁会被咬出弧形。工程师调的其实就是这个平衡。

> [!NOTE]
> **📖 名词｜鞘层（Sheath）**
>
> - **定义**：等离子体和晶圆（或腔壁）之间一层很薄的强电场区，离子一通过这里就被加速。
> - **现场用法**：「这道鞘层太厚，离子能量太高，选择比会掉。」
> - **相关名词**：偏压、离子能量、离子密度、方向性
> - **常见混淆**：鞘层不是「等离子体的一层」。它是等离子体和固体交界处形成的电位差区域，厚度随压力和功率改变。

离子能不能笔直地走，取决于它在路上会不会撞到别的分子。腔体压力越低，气体越稀薄，离子从鞘层到晶圆的途中越不会被撞歪，方向性越好；压力一高，离子东撞西撞，进到孔里的角度就散了，侧壁开始被斜着打，形状就走样。

这是为什么干法刻蚀几乎都在低压下操作。

## 等离子体：刻蚀的工具

**等离子体**是气体被高能量激发后的状态，里面混合了离子、电子和非常活泼的原子团，常被称为物质的第四态。

刻蚀设备在真空腔体中通入特定气体，再用射频电力把它变成等离子体，腔体里会发出微弱的光。

等离子体中的活泼原子团负责和材料发生化学反应，离子则负责提供方向，两者合作，才能又快又准地往下挖。

那道光既是副产品，也是信息。

气体被激发后回到低能态会发光，不同成分发出的波长不一样；工程师盯着某几个波长看，就知道腔体里的化学正在怎么变——这就是后面终点检测的原理。

设备里有几个关键部位：把气体均匀洒进来的喷头、承载晶圆并施加偏压的电极、把晶圆吸住并控温的静电吸盘、以及把废气抽走的真空泵。

射频功率主要决定「有多少离子」，偏压主要决定「离子有多快」；这两件事分开调，工程师才有办法在刻蚀速率和选择比之间找平衡。

---

## 刻蚀要看哪些指标

- **刻蚀速率**：每分钟可以挖多深。
- **均匀度**：晶圆上不同位置挖得是否一样。
- **选择比**：要挖的材料和不想挖的材料，刻蚀速度差多少。
- **轮廓**：侧壁是不是笔直，有没有往内缩或往外凸。
- **CD 变化**：刻蚀后的线宽和光刻后相比，变了多少。

这五项各自对应一种「后面会出事」的方式：

| 指标 | 看什么 | 超规之后谁受害 |
|---|---|---|
| 刻蚀速率 | 每分钟挖多深 | 产能，以及过度刻蚀的时间预算 |
| 均匀度 | 片内与片间的差异 | 线宽分布、深度分布，良率变成地图上的图案 |
| 选择比 | 目标材料对其他材料的速率比 | 停止层被吃穿，伤到底下的器件 |
| 轮廓 | 侧壁角、有没有内缩或外凸 | 后续填入留下空隙，电阻与可靠性 |
| CD 变化 | 刻蚀前后的线宽差 | 晶体管的速度与漏电 |
| 残留与微粒 | 该挖的挖干净了没 | 断路、短路、接触不良 |

> [!NOTE]
> **📖 名词｜选择比（Selectivity）**
>
> - **定义**：目标材料的刻蚀速度，和其他材料刻蚀速度的比值。选择比越高，越能只挖想挖的材料。
> - **现场用法**：「这道对氮化硅的选择比不够，停止层被吃穿了。」
> - **相关名词**：刻蚀停止层、过度刻蚀、光刻胶消耗
> - **常见混淆**：讲选择比时一定要说清楚是「对什么材料」。对光刻胶的选择比和对下层材料的选择比，是两个不同的数字。

---

## 怎么知道什么时候该停

刻蚀挖穿目标材料、碰到下一层时，等离子体中的化学成分会改变，发出的光的颜色和强度也跟着改变。

设备持续监测这个光，就能判断什么时候挖到底了，这叫做**终点检测**（Endpoint Detection）。

实际做法是挑一个只属于目标材料的波长，盯着它的亮度。挖到下一层，那个信号会突然掉下去或跳上来。

信号好不好看，取决于开口面积：图形密、开的口大，信号清楚；开的口很小，信号只在一大片背景里微微变动，就得靠更长的采样或更灵敏的算法。

到达终点后，通常还会再多刻蚀一点点，确保整片晶圆上的材料都清干净，这叫**过度刻蚀**（Over Etch）。

挖不够会留下残留，挖太多则会伤到下层。

多刻蚀的那一段，通常是一到三成的额外时间。

这个比例不是随便定的：晶圆中心与边缘的速率本来就有差，图形密的地方和疏的地方也不一样，过度刻蚀就是在「补这些差异」。所以选择比不够的时候，先撑不住的不是终点，是那一段多出来的时间。

## 刻蚀之后

刻蚀完成后，先用氧等离子体把光刻胶烧掉，称为**去光刻胶**（Ashing 或 Strip），再经过清洗，接着测量线宽和缺陷，这个检查称为 **AEI**（After Etch Inspection）。

去光刻胶看起来只是「把不要的东西清掉」，其实有两件事要一起处理。

一件是光刻胶本身，氧等离子体把它烧成气体；另一件是刻蚀时留在侧壁和底部的聚合物，那些东西不是有机物，氧等离子体烧不掉，要靠湿法药液。

只做干法、不做湿法，聚合物会留到下一站变成缺陷。

刻蚀也是整条线的咽喉。它的深度决定 CMP 要磨掉多少——挖得太深，CMP 为了磨平得吃更多，连不该磨的地方都磨掉；挖得太浅，后面的金属填不满。它的侧壁形状决定薄膜盖不盖得住，而薄膜盖不住，注入就会从缝里钻进去。这些账通常要到电学测试才结算。

AEI 量到的线宽，会和光刻量到的线宽相比；两者的差就是刻蚀加上去的部分。这个数字回到光刻，成为下一批曝光条件的修正依据——这是两站之间每天在做的一次对账。

和光刻不同，刻蚀做坏了通常无法重来，因为材料已经被挖掉了。

而且刻蚀会在表面留下一层被离子打伤的薄层，结构已经不是原本的样子；这层损伤要在后面的步骤里想办法处理，处理不掉就会变成漏电或接触电阻。

## 越挖越深：高深宽比刻蚀

存储器等产品需要挖出非常深又非常窄的孔，深度可以是宽度的数十倍。孔越深，离子越难抵达底部，刻蚀速度会变慢，孔也可能变弯、扭曲，或是中段被挖得比较宽。这是目前最困难的工艺之一，见[第 13 章](../../3-integration/13-memory/README.md)。

越深越难，背后有三个原因。

第一是**传输**：反应气体要进得去、副产物要出得来，孔越深越难交换，底部自然长得慢。第二是**角度**：离子不可能百分之百垂直，总有一点发散，走进深孔后，稍微斜一点的离子就打到侧壁，把孔挖成弧形。第三是**带电**：绝缘的掩模和侧壁会累积电荷，把后来的离子推偏，孔底就开始歪。

这三件事加起来，就是高深宽比刻蚀的难处：同一个孔，上段、中段、下段的形状可能都不一样。

工程师的对策是把条件拆开——分段改变气体比例、用脉冲的方式供电让电荷有时间散掉、在侧壁重新补一层保护。做得好的时候，一个孔从头到底的直径差异可以控制在很小的范围；做不好的时候，孔底会歪到接不上下一层。

## 刻蚀的账单：产能、成本与寿命

刻蚀是单片工艺，一片一片进腔体，所以产能直接被「一片多久」锁住。

干法刻蚀的速率大约每分钟数百纳米，一片晶圆要挖的深度从几十纳米到几微米，换算下来一片一到三分钟。

设备通常有好几个腔体并行，同一批晶圆分散进去，一小时处理数十片是常见的量级。

| 成本项目 | 内容 | 特性 |
|---|---|---|
| 设备折旧 | 刻蚀机、真空泵、射频电源 | 固定成本，开不开机都在烧 |
| 气体 | 含氟、含氯的反应气体，加上氩气与氧气 | 变动成本，部分气体单价高 |
| 零件 | 腔体衬里、电极、遮挡环、静电吸盘 | 消耗品，数百到数千片换一次 |
| 保养停机 | 定期清腔、更换零件、重新建立腔体状态 | 不生产，但折旧与人力照算 |
| 电力与尾气 | 射频功率、真空泵、废气处理 | 单片式设备耗电高 |

气体那一项值得多说一句。含氟的刻蚀气体有些温室效应潜势极高，排放法规管得紧，所以设备后面通常接着燃烧或等离子体式的尾气处理装置，把残余气体分解掉。这套装置的购置与运转费用，最后也会摊到每一片上。

零件寿命是另一个容易被低估的项目。

等离子体会侵蚀腔体内壁，工程师会在里面放可更换的衬里，让它替腔壁挡着；衬里被吃掉就要换，换完还要重新建立稳定的表面状态。所以刻蚀的成本不是「气体加电力」，而是「气体加零件加停机」。

> [!TIP]
> **🔧 Know-how｜清洁完的腔体要先「养」一下**
>
> - **情境**：刻蚀腔体刚做完保养，内壁被清洁得干干净净。
> - **做法**：先跑一些挡片，让腔体内壁盖上一层稳定的沉积物，再开始跑产品。这个步骤现场叫 **Seasoning**。
> - **为什么**：等离子体会和腔体内壁互相作用。内壁的状态不同，等离子体的成分就不同，刻蚀速率也会跟着变。
> - **没做会怎样**：保养后的前几批晶圆刻蚀结果偏移，可能造成线宽或深度异常。
> - **相关章节**：[第 1 章 晶圆厂如何运行](../../0-before-you-start/01-how-a-fab-works/README.md)

> [!TIP]
> **🔧 Know-how｜同一台设备，不同腔体也要比对**
>
> - **情境**：一台刻蚀机通常有好几个腔体，同一批晶圆会分散到不同腔体处理。
> - **做法**：工程师会定期比对各腔体的结果，让它们尽量一致，系统也会记录每片晶圆是在哪个腔体做的。
> - **为什么**：腔体之间的微小差异，会让晶圆之间出现系统性的差异。
> - **没做会怎样**：同一批晶圆中有几片表现特别差，却查不出原因。有腔体记录，才能找出「问题都出在同一个腔体」。
> - **相关章节**：[第 16 章 良率与失效分析](../../4-yield-and-quality/16-yield-analysis/README.md)

> [!TIP]
> **🔧 Know-how｜光刻胶不是无敌的**
>
> - **情境**：光刻留下的光刻胶，要在刻蚀时当掩模用。
> - **做法**：工程师会估算这道刻蚀会消耗掉多少光刻胶，回头要求光刻把光刻胶涂到足够的厚度，并在刻蚀条件上控制对光刻胶的选择比。
> - **为什么**：光刻胶是有机物，会被离子和自由基一起侵蚀；刻蚀越久、功率越高，光刻胶掉得越快。
> - **没做会怎样**：图形在刻蚀中途失去掩模，边缘被啃掉，CD 变宽或图形直接消失。
> - **相关章节**：[第 4 章 光刻](../../2-process-modules/04-lithography/README.md)

## 常见异常

| 异常 | 可能原因 | 结果 |
|---|---|---|
| 刻蚀不足 | 时间或功率不足、终点判断错误 | 残留材料，造成断路 |
| 过度刻蚀 | 选择比不足、时间太长 | 伤到下层材料 |
| CD 偏移 | 侧壁轮廓改变、光刻胶消耗太多 | 线宽不合格 |
| 微粒 | 腔体内壁的沉积物剥落 | 缺陷、短路 |
| 负载效应 | 图形密的地方和疏的地方刻蚀速度不同 | 同一颗裸片内深度不一致 |
| 侧壁弯曲 | 离子散射、侧壁保护不足 | 后续填入留下空隙 |
| 孔底倾斜或扭曲 | 深孔中电荷累积、掩模不平 | 上下层接不上 |
| 微掩模 | 颗粒或聚合物碎屑落在表面 | 局部挖不下去，留下柱状残留 |
| 电荷损伤 | 等离子体不均、电荷无处可去 | 栅极绝缘层受损、漏电变大 |

---

## 本章重点

1. 刻蚀把光刻胶上的图形转印到底下的材料上，是减法工艺，做坏了补不回来。
2. 湿法刻蚀是各向同性的，干法刻蚀用等离子体可以做到各向异性，现代细微图形主要靠干法刻蚀。
3. 方向性来自离子，化学反应来自自由基，侧壁靠聚合物保护，三者平衡才有笔直的侧壁。
4. 选择比决定能不能「只挖想挖的材料」；终点检测通过等离子体发出的光，判断什么时候该停。
5. 深宽比一高，传输、角度与带电三个问题同时出现，形状很难从头到尾一致。
6. 刻蚀做坏通常无法重来，所以腔体状态、零件寿命与保养节奏的管理特别重要。
