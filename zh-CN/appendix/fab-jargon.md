# 附录 B　现场行话

晶圆厂的日常沟通，常常是中文夹杂英文术语，例如「这批 Q-Time 快到了，先跑它」。刚入行的人第一次听到，常常一头雾水。

本附录收录晶圆厂里常听到的说法，并附上例句。各公司的习惯用语不完全相同，本附录保留原作的现场行话；不同地区与工厂可能使用不同称呼，不能据此认为所有说法在中国大陆通用。标注「台湾现场用语」者，为台湾晶圆厂常见、大陆不一定通用的说法。正式的术语定义请见[附录 A 术语总表](glossary.md)。

行话大概可以分成三种。一种是**术语**，例如 Q-Time、Overlay，指的是有明确定义的东西；一种是**动作**，例如进站、Release、Bank，指的是某个人当下要做的事；还有一种是**状态**，例如 Down、Hold、Idle，指的是某个东西现在怎么样。听话的时候先分辨是哪一种，通常就不会误会。

---

## 晶圆与批次

这一区的行话最常出现在交接班、派工与生管会议上。判断一句话是「描述现状」还是「要求动作」，是听懂它的关键。

| 行话 | 意思 | 例句 |
|---|---|---|
| Lot | 一批晶圆，最多 25 片 | 「这个 Lot 今天要出货。」 |
| 投片（Wafer Start） | 把空白晶圆投入生产 | 「这个月的投片量增加了。」 |
| 组批 | 把几片晶圆组成一批，凑满一个晶圆盒 | 「今天的组批进度落后，生管在催。」 |
| 拆批（Split） | 把一批晶圆分成几组，做不同条件 | 「这批要 Split 成三组条件。」 |
| Merge | 把分开的晶圆合回同一批 | 「实验做完就 Merge 回去。」 |
| 尾批 | 数量不满一整盒的批次 | 「尾批先跑，别让它卡在炉管前面。」 |
| Fab Out | 晶圆完成前段工艺，离开晶圆厂 | 「这批预计下周 Fab Out。」 |
| Hot Lot | 优先生产的急件 | 「这批是 Hot Lot，到站先跑。」 |
| Bank | 让晶圆暂停在某个步骤等待 | 「这批先 Bank 在金属层前面。」 |
| WIP | 还在生产线上的晶圆 | 「光刻区前面的 WIP 堆太多了。」 |
| Move | 一段时间内晶圆完成的步骤数，用来衡量产出 | 「今天全厂的 Move 达标了吗？」 |
| 控片 | 用来检查设备状态的测试晶圆（Monitor Wafer） | 「先跑一片控片确认膜厚。」 |
| 挡片 | 用来填补空位或调整设备状态的晶圆（Dummy Wafer） | 「炉管空位记得补挡片。」 |
| 破片 | 晶圆破裂 | 「机械臂取片时破片了。」 |
| 划伤 | 晶圆表面被划出痕迹 | 「这片的 Map 有一条划伤，先隔离。」 |

## 设备

设备这一区的行话，多半是在讲「它现在能不能跑」。所以最常听到的是状态词，而不是技术词。

| 行话 | 意思 | 例句 |
|---|---|---|
| Recipe | 设备执行工艺用的参数组合 | 「这道的 Recipe 换新版本了。」 |
| PM | 定期保养 | 「这台今天下午排 PM。」 |
| Down（Down 机） | 设备故障或停用 | 「刻蚀机 Down 了，已经通知 EE。」 |
| 复机 | 设备修好、恢复生产 | 「这台预计晚上复机。」 |
| Qual | 确认设备状态合格的验证 | 「PM 完要先 Qual 过才能跑货。」 |
| Seasoning | 保养后先跑挡片，让腔体稳定 | 「先 Season 二十片挡片。」 |
| 暖机 | 开机或闲置太久后，先跑几片让状态回稳 | 「这台刚暖机，先别排急件。」 |
| Chamber | 设备中实际做工艺的腔体 | 「这片是在 B 腔做的。」 |
| Idle | 设备闲置、没有晶圆可跑 | 「这台 Idle 很久了。」 |
| 绑机（Dedication） | 指定晶圆只能在特定设备上做（台湾现场用语） | 「这层要绑同一台曝光机。」 |
| 借机 | 向别的区域或厂区借用设备产能 | 「这批要借机跑，先确认 Recipe 有没有。」 |
| UPH | 每小时产出片数 | 「这台的 UPH 掉了一成，要查一下。」 |
| Alarm | 设备发出的异常信号 | 「昨晚这台跳了三次 Alarm。」 |
| Load Port | 设备前方放晶圆盒的平台 | 「Load Port 读不到 FOUP 的编号。」 |

## 系统与流程

这一区是新手最容易卡住的地方，因为同一个词可能同时是「系统上的状态」和「现场的动作」。听到「Hold」时，要问的是「谁 Hold 的、为什么」。

| 行话 | 意思 | 例句 |
|---|---|---|
| 进站（Track-in） | 在系统上登记开始加工 | 「货放上去记得先进站。」 |
| 出站（Track-out） | 在系统上登记完成加工 | 「设备跑完了，记得出站。」 |
| Hold | 暂停晶圆或设备的生产 | 「这批被 Hold 了，原因是 Q-Time 超过。」 |
| Release | 解除 Hold，放行继续生产 | 「工程师确认没问题，可以 Release。」 |
| Future Hold | 让晶圆走到指定步骤时自动被挡下 | 「先设 Future Hold，到金属层再决定。」 |
| 改派（Re-route） | 把晶圆改走另一条流程或另一台设备 | 「这台要保养，这批改派到隔壁线。」 |
| Q-Time | 两站之间允许等待的时间 | 「这批 Q-Time 快到了，先跑它。」 |
| 派工 | 决定设备下一批要跑哪一批晶圆 | 「派工系统把这批排在最前面。」 |
| 跑货 | 让产品晶圆在设备上生产 | 「这台现在可以跑货了吗？」 |
| 账实不符 | 系统记录和实际状况不一致 | 「系统显示已出站，晶圆却还在设备里，账实不符。」 |

## 系统与数据

这一区的行话，这二十年增加得最快。以前工程师靠笔记本和经验，现在靠报表和系统；听得懂这些词，才进得了早会。

| 行话 | 意思 | 例句 |
|---|---|---|
| 履历（Lot History） | 一批晶圆走过的步骤、设备、时间与测量结果 | 「拉一下这批的履历，看它经过哪些腔体。」 |
| 拉数据 | 从系统导出某段时间或某批的生产数据 | 「先拉三个月的数据，看有没有周期性。」 |
| 共性 | 异常批次共同经过的设备、腔体或时段 | 「这几批的共性是同一台刻蚀机的 B 腔。」 |
| 开图 | 调出控制图或趋势图看变化（台湾现场用语） | 「这支参数上周就开图了，一直没收敛。」 |
| 回写 | 把测量或测试结果写回生产系统 | 「测量数据还没回写，先别放行。」 |
| 虚拟测量 | 用设备数据推估测量结果，取代部分实际测量 | 「这站有开虚拟测量，抽样可以少一点。」 |
| FDC 报警 | 设备传感器数据偏离正常范围的警示 | 「昨晚 FDC 报警了十几次，都是同一支气体。」 |
| 绑批 | 把前后批次的关系记录下来，用于追溯 | 「这两批要绑批，客户要求整串追溯。」 |

## 质量与异常

这一区的词听起来都很严重，但实际上大部分事件最后只是「记录、检讨、结案」。真正的判断点是：这件事会不会影响已经出货的产品。

| 行话 | 意思 | 例句 |
|---|---|---|
| OOC | 数据超出控制限 | 「这点 OOC 了，照 OCAP 处理。」 |
| OOS | 数据超出规格 | 「膜厚 OOS，要开 MRB。」 |
| Rework | 重新制作，主要用在光刻 | 「ADI 没过，要 Rework。」 |
| Scrap | 报废 | 「这片破片了，只能 Scrap。」 |
| 特采 | 不合格但经核准后仍可使用（让步接收） | 「这批走特采，客户已经同意。」 |
| 降级 | 把产品降到较低规格出售 | 「速度没过，降级成低阶型号。」 |
| 隔离 | 把有疑虑的晶圆单独存放，暂不投入 | 「先隔离，等 FA 结果出来再说。」 |
| Excursion | 突发的质量异常事件 | 「昨天那次缺陷的 Excursion 影响了三批。」 |
| MRB | 跨部门判定不合格品处置方式的会议 | 「这批要开 MRB 决定。」 |
| Map | 晶圆图 | 「看一下这片的 Map 有没有划伤。」 |
| Particle | 微粒 | 「这片的 Particle 数超标。」 |

## 可靠性与固件

这一区的行话，出现在测试、客诉与固件会议上。它们的共同点是：问题通常不会马上出现，而是几个月后才回来。

| 行话 | 意思 | 例句 |
|---|---|---|
| 老化（Burn-in） | 在高温高压下运行一段时间，筛掉早期失效 | 「这批要老化 48 小时。」 |
| 刷新（Refresh） | 定期重写 DRAM 数据 | 「高温时刷新频率要加倍。」 |
| 开 ECC | 启用纠错功能 | 「这颗控制器默认没开 ECC，要记得开。」 |
| 勘误（Errata） | 芯片已知问题与避开方法 | 「这条勘误要在固件里补 workaround。」 |
| 改版（Stepping） | 芯片修正设计后的版本代号 | 「新版是 B0，只改了金属层。」 |
| 擦写次数（P/E） | 闪存块能被擦写的次数 | 「这批 TLC 的 P/E 只剩几百次。」 |
| 写放大 | 主机写一份，实际写进闪存几份 | 「写放大跑到 3，寿命会差很多。」 |
| 客退（RMA） | 客户退回的故障品 | 「这颗是客退品，先做 FA。」 |

## 区域与人

最后一区讲的是「谁在做什么」。晶圆厂的分工很细，找错人会绕很大一圈。

| 行话 | 意思 | 例句 |
|---|---|---|
| 黄光 | 光刻区，因照明是黄色而得名（台湾现场用语） | 「这批卡在黄光。」 |
| 炉管 | 氧化、退火等批式高温设备的区域 | 「炉管今天组批比较慢。」 |
| Wet | 湿法清洗与湿法刻蚀区 | 「这道要先到 Wet 洗一下。」 |
| PE、EE、PIE、YE | 工艺、设备、工艺集成、良率工程师 | 「这个问题要找 PIE 判断。」 |
| AE | 应用工程师，负责客户端技术支持 | 「客户那边由 AE 先确认现象。」 |
| QA | 质量保证 | 「这个变更要 QA 签过。」 |
| 值班 | 下班时间与假日负责处理异常的人 | 「今天值班是谁？设备跳 Alarm 了。」 |
| 交接 | 换班时说明设备与晶圆的状况 | 「交接时要讲清楚这台还在观察。」 |
